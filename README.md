# Oxbow macroinvertebrates

Data and analysis scripts for the manuscript:

**Macroinvertebrate assemblages differ in composition but not aggregate diversity between floodplain and levee-protected oxbow lakes**

## Authors

Csaba Békési, Tamás Bozóki, Júlia Szeles, Emese Gyökeres, Judit Fekete, Áron Lukács, Zoltán Csabai, Gábor Várbíró, Pál Boda

## Study

We analysed aquatic macroinvertebrate assemblages from **22 Hungarian oxbow lakes along the Danube and Tisza rivers**, comparing floodplain and levee-protected systems.

The repository contains data and R scripts for analyses of:

- taxonomic and functional diversity
- community composition
- indicator taxa
- environmental and landscape effects
- variation partitioning
- exploratory path models

The main result is that floodplain and levee-protected oxbows differ more clearly in **taxonomic composition** than in aggregate diversity metrics.
